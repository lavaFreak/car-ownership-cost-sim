Monte Carlo Cost Explorer

Build a scenario, then open a dedicated ownership-cost report.

Use this page to choose the vehicle, enter assumptions, and tune the cost model. When you generate the report, the results open on their own page so the analysis is easier to review and share.

Workflow
  1. Pick a year, make, model, and exact catalog match when available.
  2. Adjust the cost assumptions or keep the suggested defaults.
  3. Generate a report page with the simulated cost distribution and yearly breakdown.

Vehicle and usage

When enabled, the simulator uses the selected region for sales tax, registration, fuel or electricity pricing, and charging defaults. Turn it off to customize those assumptions manually.

Starting age and odometer let the wear, repair, and resale model behave more like a used-car scenario instead of assuming every purchase begins at zero miles.

Plug-in hybrid electric usage

Plug-in hybrids can split miles between electricity and gasoline. These fields estimate what share of miles stay electric and how efficient the vehicle is in EV mode.

Plug-in charging mix

These fields model how much charging happens away from home and how much energy is lost during charging. Plug-in hybrids also use this section for a separate home-electricity price assumption on top of gasoline.

What The Report Includes

Use the starter assumptions or model a car you already have in mind.

Dedicated analysis page

Generating the report opens a separate page with the full outcome distribution, comparison tools, and year-by-year breakdown.

What you will see

  • Average, median, and percentile cost ranges
  • One sampled ownership scenario broken into cost categories
  • Annual cash flow and final-total contribution by year
  • Comparison mode for pinning one run against another

Shareable scenario links

Copying a report link preserves the current scenario so someone else can open the same inputs directly on the report page.
